# Josefina para Android

Aquí solo se publica el archivo de instalación de la app de Josefina, un asistente personal privado,
y `version.json`, que la app consulta para ofrecer las versiones nuevas desde dentro.

No lleva claves ni datos: sin la contraseña de su dueño no sirve para nada.

Para instalarla a mano: abre [josefina.apk](https://raw.githubusercontent.com/mateos22dos/josefina-descargas/main/josefina.apk) en el móvil.
